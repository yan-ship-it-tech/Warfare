## Licensing constraints that apply to anything sourced here

- **Binary assets can't be fetched from an agent session** — this environment's egress proxy blocks them, so a downloaded model would be a license assumed rather than read. Sourced models/images need a human to download and check the licence. See `CLAUDE.md`.
- **Anything sourced must carry attribution** in the app where it's rendered — the same obligation `data/osm/` already carries for OpenStreetMap (ODbL).
- **CC BY-NC-ND models are a trap** for anything that might be reused commercially — the Pass 16 manifest flags at least one (Shahed-136).
- Imported geometry still has to meet `docs/MODEL_STYLE_GUIDE.md` (proportions, poly budget, palette) — a 190k-tri Orlan-10 needs decimating before it goes near the map view.
